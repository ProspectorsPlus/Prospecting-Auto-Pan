Install Prospector Lite on Windows

Five short steps: download two files, check the fingerprint, run the installer, open the app, and finish setup inside it. Nothing here needs administrator rights, and nothing asks you to weaken Windows security.

Step 2

Check the fingerprint

A checksum is a fingerprint of a file. Prospector Lite publishes a SHA-256 fingerprint for each release file. If the fingerprint of the file on your computer matches the published value, the download has not changed since it was released.

SHA-256 is the recipe that computes the fingerprint. It reads every byte of the file and turns them into a 64-character code. Changing even a single byte anywhere in the file produces a completely different code, so a matching code means an identical file. The code only works one way; nobody can build a different file that produces the same fingerprint.

The Windows builds are not code signed yet, which makes this check the real integrity test. It also sets up step 3: once the fingerprint matches, you can answer the SmartScreen warning with actual evidence about the file.

Run the check

  1. Press the Windows key, type powershell, and press Enter. A blue or black text window opens.
  2. Move PowerShell into your Downloads folder:
    PowerShell
    cd "$HOME\Downloads"
  3. Paste this whole block and press Enter. It reads the published fingerprint out of SHA256SUMS.txt, computes the fingerprint of your download, and compares them for you:
    PowerShell
    $file = "ProspectorLite-5.0.0-Windows-x64-Setup.exe"
$expected = (Select-String -Path ".\SHA256SUMS.txt" -Pattern ([regex]::Escape($file))).Line.Split(" ")[0]
$actual = (Get-FileHash ".\$file" -Algorithm SHA256).Hash.ToLower()
if ($actual -eq $expected) { "OK: $file matches the published fingerprint" } else { "MISMATCH: do not run this file" }
  4. Read the result. You want this line:
    Expected output
    OK: ProspectorLite-5.0.0-Windows-x64-Setup.exe matches the published fingerprint

Downloaded the portable ZIP instead? Change the first line to $file = "ProspectorLite-5.0.0-Windows-x64-Portable.zip" and run the same block.

Or compare by eye

If you prefer to see the raw fingerprint, compute it directly:

PowerShell
Get-FileHash ".\ProspectorLite-5.0.0-Windows-x64-Setup.exe" -Algorithm SHA256

PowerShell prints the fingerprint in capital letters; letter case does not matter, but every character does. The published values for 5.0.0:

Installer:
242081f0dea0cd2aaf5b502ce425c6ea9b6cf883e5e1ac8add293c2364338102

Portable ZIP:
b0c035b9cd3697e6e6758c8e4e24cd4a2dc3965b900d930cd7407198725921e9

These values come from the release's SHA256SUMS.txt, produced by the build pipeline at release time. The copy in your Downloads folder should contain exactly the same lines.

What OK means

OK means the bytes on your disk are identical to the bytes we released: nothing altered the file between our release pipeline and your Downloads folder, and the download completed fully. It says nothing about whether you trust the software itself; for that, the source code and the trust documentation are public.

MISMATCH means the file is not the released build. An interrupted download is the usual cause. Delete the file, download it again from the release page, and re-run the check. If it fails twice, stop and report it; do not run the file.

If a file was renamed or is missing

  • An error naming a missing file (for example Cannot find path) means PowerShell is not in the folder that holds your downloads, or the file has a different name. Run cd "$HOME\Downloads" again, then dir Prospector*, SHA256* to see what is actually there.
  • Downloaded the checksum list twice? Browsers save the second copy as SHA256SUMS (1).txt instead of overwriting. Delete the extra copy, or rename it back:
    PowerShell
    Rename-Item ".\SHA256SUMS (1).txt" "SHA256SUMS.txt"
    The quotes matter: the space and parentheses would otherwise split the name into separate arguments. If a plain SHA256SUMS.txt already exists, delete one copy first so only one remains.
Step 3

Install it

The installer

  1. Double-click ProspectorLite-5.0.0-Windows-x64-Setup.exe in your Downloads folder.
  2. Windows shows a blue "Windows protected your PC" SmartScreen dialog. Click More info, then Run anyway. Why this warning appears on a genuine copy, and why that click is the correct response after step 2, is explained just below.
  3. Follow the installer. It installs only for your user account, so there is no administrator prompt and nothing system-wide changes.
  4. Finish with the Start menu shortcut in place; the last page can launch Prospector Lite directly.

About the SmartScreen warning

SmartScreen judges files by reputation: how often Windows has seen them and whether they carry a code-signing certificate. Prospector Lite 5.0.0 is unsigned and new, so the warning appears even on a genuine copy. Your checksum from step 2 gives you something stronger than a reputation score: direct evidence that this exact file is the released build. With a matching fingerprint, More info, then Run anyway is the correct response.

Leave SmartScreen itself switched on; it keeps protecting every other download. The same goes for Microsoft Defender: if it flags a file whose checksum matches, report it as a false positive to Microsoft and open an issue rather than turning anything off. A flagged file whose checksum does not match is simply a bad download; delete it.

The portable ZIP instead

  1. Right-click ProspectorLite-5.0.0-Windows-x64-Portable.zip and choose Extract All, then pick any folder you like.
  2. Open the extracted Prospector Lite folder and run Prospector Lite.exe. SmartScreen may show the same warning once; answer it the same way.
  3. That is the whole install: delete the folder later to remove it.
Never run Prospector Lite as administrator. It is never required, and if Roblox itself runs elevated, the fix is to run both programs at the normal level, never to elevate the macro.
Step 4

First launch

The first start opens a five-page setup wizard: Welcome, Trust and Permissions, Guided Calibration, Readiness Check, and then the app itself. Progress is saved after every page, so closing the app and coming back later resumes where you left off. You can re-run the wizard any time from the Tutorial menu.

Windows shows no permission prompts. The operating system lets desktop apps read the screen and send input without a grant system, so instead of pretending there is a switch, each capability card offers a real Test: a one-shot screen grab that is shown once and discarded, a sandboxed keystroke plus a two-pixel pointer wiggle, and an eight-second Safe Stop listen for Esc. Run all three; green results mean the machine is ready.

The app stores everything in one local folder, listed live in the Trust Center with open, export and delete actions:

%APPDATA%\Prospector Lite

Paste that into the File Explorer address bar to jump straight there. If you used the old private "Prospectors Plus" app, the first run copies its settings over once; the old folder is never modified.

If something fails

  • The installer never opens. Re-run the fingerprint check first; a MISMATCH means a broken download. If it matches, look for the SmartScreen dialog hiding behind other windows.
  • The macro presses keys and nothing happens in Roblox. Roblox is probably running as administrator; run both programs at the normal level. See Windows install issues.
  • Defender quarantined the file. Verify the checksum of a fresh download. Matching: report a false positive and open an issue. Not matching: delete it.
  • Anything else. The Troubleshooting and FAQ page covers detection, timing and permission symptoms one by one.
