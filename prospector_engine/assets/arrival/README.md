# Arrival assets

Empty on purpose.

`E-ARRIVE` (plan §7.4) has not been run, so there is no validated arrival
template, glyph outline, or reference crop to ship. The one supplied positive
screenshot is a fixture seed, not a validation corpus, and putting it here
would make an unvalidated asset look like a shipped detector.

Populate this directory only from a frozen, passed `E-ARRIVE` evaluation, and
record the `evaluation_spec_id` alongside each asset.
